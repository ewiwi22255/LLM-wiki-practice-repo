刪除 GPS ≠ 保護位置：車速＋方向盤就能還原路徑

921→43 m
加入道路圖後，5 分鐘片段的中位位置誤差（方向盤航位推算 → 線上粒子濾波器）
56→87%
在速度之外加上方向盤訊號後，5 分鐘路徑還原率
≥82.6%
即使方向盤量化到 10°、速度量化到 1 m/s 等最嚴苛劣化，仍能還原的路徑比例
  • 資料收集者遍布：用量計費保險、車隊管理、售後駕駛輔助、公開駕駛資料集

問題 ① · 手機感測器

不需要任何權限，磁力計就知道你在哪班車上

16.7 Hz
中北歐交流電氣化鐵路的牽引電流頻率，在車廂內可量測
0.93
只用磁力計偵測「正在搭電車」的 MCC（F1 0.98）
0.79
比對兩支手機的磁場軌跡，推論「同車」的 MCC（F1 0.89）
0 權限
Android（上限 200 Hz）與 iOS（上限 100 Hz）都允許免權限讀取

誰會這樣做？

被入侵的第三方 SDK（例如廣告商）大規模追蹤，或被竄改的通訊 App 鎖定特定對象。只要有一條已知位置的參考軌跡，同行推論就能直接暴露其他人的位置。

論文的建議

磁力計應需要明確權限；或把免權限的取樣率壓在 35 Hz 以下，16.7 Hz 成分就無法擷取。

「降低訊號品質」能防禦嗎？兩篇給出相反答案

問題 ② · 簽章標準

Bitcoin／Ethereum 的簽章，建立在一個沒人證明過的假設上

RFC 6979 用 HMAC_DRBG(私鑰 ‖ 雜湊) 產生 ECDSA nonce。作者指出它真正需要的是假設 A*：「已知公鑰時，這樣產生的簽章紀錄與隨機 nonce 不可區分」。

  • 反例：存在一個標準意義下的 PRF，用它產生 nonce 卻只要一個簽章就能還原私鑰。所以「HMAC 是 PRF」推不出 RFC 6979 安全
  • A* 與 AI-PRF 互不蘊含；目前沒有已知攻擊，但也沒有標準模型的證明
28/31
個 secp256k1 實作預設使用確定性簽章，不加額外熵
0
個實作採用可以免除 A* 的「獨立 nonce 金鑰」（RFC 6979 §3.6）
0
個實作測試 h ≥ n 分支（論文附錄 B 補上測試向量）
3
個移植版沿用舊行為（NBitcoin、dcrd、btcec v2），屬於相容性 bug，波及 LND、go-ethereum
來源：RFC 6979 確定性 ECDSA（arXiv 2611.18449）p.1、p.4、p.14–18 · secp256k1-implementations

問題 ② · 安全基礎的光譜

要可公開驗證，還是要無條件安全？

計算安全：ECDSA · EdDSA · ML-DSA資訊理論安全：USS · IT 門檻簽章

計算安全

  • 任何人都能用公鑰驗證，金鑰短
  • 依賴困難度假設，而且像 A* 這樣的假設可能根本沒被證明
  • 後量子方案（格）仍然是計算安全

資訊理論安全（IT 門檻簽章，2026）

  • 面對無限算力（包括量子）攻擊者，偽造機率 ≤ 1/pΔk
  • 代價：只有預先登記的驗證者能驗證、金鑰只能用一次、金鑰很長
  • Raspberry Pi 4 最壞情況：簽章約 232 ms、驗證約 2 s；無 dealer 簽章 ≤ 250 ms，Threshold ML-DSA-87 約 560 ms
比較適合成員固定的封閉系統，例如無人機群、工業控制、支付基礎設施。推論
來源：digital-signatures · IT 門檻簽章（arXiv 2611.18355）p.1、p.9、p.13

跨領域主題

旁通道的三種載體：秘密總是從「副作用」流出去

微架構狀態

分支預測錯誤時，推測執行讀到秘密，並在快取中留下痕跡（Spectre v1）。

防禦：SLH、SCT 型別系統

nonce 位元外洩

功耗或時間洩漏 ECDSA nonce 的部分位元。256 位元曲線上一個外洩位元，模型估計約需 240–247 個簽章才能利用。

防禦：hedged 簽章、獨立 nonce 金鑰

環境物理訊號

架空線的牽引電流產生磁場，手機感測器不需要權限就能量到。

防禦：感測器權限、取樣率上限

三個社群（系統、密碼學、行動隱私）研究的是同一類問題，但用語與評估方式差異很大。把列車磁場論文歸為旁通道，是 wiki 的分類。推論
